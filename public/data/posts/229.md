**2.**怎么获取选择的结果呢，很简单，利用doClick函数就好了：

 

select = new LSelect(0, 200, 250, 220) {
 

                        @Override
 
                        public void doClick() {
 
                                msg.setMessage("答案：");
 
                                Log.d(TAG, "doSelect: " + this.getResult());
 
                                Log.d(TAG, "doSelect: " + this.getResultIndex());
 
                        }
 
                        
 
                };

  
 

getResult函数是直接获取点击的选项的字符串；

getResultIndex函数是获取点击的选项的索引。
